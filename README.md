# 调查员之书 · COC 7版 调查员角色卡交互式创建工具（coc7r 分支）

克苏鲁的呼唤（Call of Cthulhu）TRPG 第七版调查员角色卡交互式创建网页，Vue 3 + Vite 构建。

> **分支说明：`coc7r`**
> 本分支按《克苏鲁的呼唤：守秘人伴侣》修订版（CHA23197）调整规则，供通用模组使用。相对 `main` 的差异：
> - 属性：购点改为 **480 点**（单项上限 90，建议下限 30）；移动率＝**7 起**，力量大于体型 +1、敏捷大于体型 +1
> - 技能：魅惑／话术／恐吓**合并为「说服」**；新增**安抚**（基础值＝外貌÷5）与**宗教**（10%，须选专长）；**取消冲锋枪技能**（冲锋枪改用火器（手枪））
> - 点数：个人兴趣点 = **教育 + 智力**
> - 职业：自建职业默认按**修订版「创建新职业」——固定 300 点**（6–12 项技能，须含信用评级），可切回经典「属性×2+属性×2」
> - 人物卡：理智三栏＝**初始值／当前值／异变阈值（意志÷5）**，理智上限（99−神话）移至神话区；生命、魔法均为初始值／当前值两栏
> - 术语：精神状态四格使用修订版用语——**惊骇／余悸／异变／迷失**
> - 背景故事：按修订版缩减重建（外貌描述、个性、重要之人与地点、特殊物品、伤势与疤痕、恐惧、我的故事），旧数据自动迁移
> - 货币：默认按国籍与时代判断，可手动切换人民币元
> - 主题：浅色纸张配色与衬线排版，与守秘人侧文档同源

数据只存在浏览器本地（LocalStorage），不注册、不联网；换设备前记得导出 JSON 备份。

### 自行构建

```bash
git clone https://github.com/CZ-Izaya/coc7r_investigator_wizard.git
cd coc7r_investigator_wizard
npm install

npm run build    # 构建单文件 HTML → dist/index.html
```

构建产物 `dist/index.html` 为单文件，可直接用浏览器打开，无需服务器。国内发布流程：构建后复制到 `site/`，再发布到托管地址（同目录同链接）。

## 功能

#### 调查员创建 & 管理

- 交互式创建：属性分配（购点／随机／快速开始）、年龄调整、职业（预设 443 种或自建）、技能分配（职业／业余，严格或通俗模式）、武器、背景故事随机表
- 交互式成长：幕间成长、属性值调整
- 调查员花名册：多卡存储、重命名、复制、批量导入导出

#### 导入 & 导出

- 导出：本工具 JSON、**图片／PDF**（Blob 下载）、骰娘 `.st` 属性串、Saiko Base64、FVTT COC7th JSON、Dhole's House JSON、**分享链接**（整卡压缩进 URL，无需服务器）
- 导入：本工具 JSON、Saiko Base64、分享链接

> 图片与 PDF 导出在微信等内嵌浏览器中不会弹出下载，请换系统浏览器打开后操作。

#### 扩展

- 调查员经历包
- 中国／日本调查员的资产与现金自动换算
- 日本 COC 扩展职业、纸浆克苏鲁扩展职业
- i18n：简体中文、日语、英语
